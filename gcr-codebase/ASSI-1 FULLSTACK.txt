SOLUTION 1


FRONTEND : I) Focuses on the user interface (UI) and user experience (UX).
           II)Designs and builds what users see and interact with.
              III)USE-HTML, CSS, JavaScript, React, Angular, Vue.js.
              IV)Directly interacts with users.
              EXAMPLE: Creating buttons, forms, menus, animations, responsive layouts.

2.BACKEND : I)Focuses on the server, database, and application logic.
            II)Processes data, handles business logic, and manages databases.
           III)USE-Python, Java, PHP, Node.js, Ruby, MySQL, MongoDB.
           IV)Indirectly interacts with users through the frontend.
            EXAMPLE:User authentication, storing data, processing payments, API development.

3.FULL-STACK: I)Combines both frontend and backend development.
              II)Develops both the client-side and server-side of an application.
              III) USE-Uses both frontend and backend technologies.
              IV)Handles both user interaction and server operations.
              EXAMPLE: Building an entire web application from start to finish.

SOLUTION 3


1)User enters a URL in the browser.
2)DNS converts the domain name into an IP address.
3)The browser sends an HTTP/HTTPS request to the web server.
4)The web server processes the request and sends back an HTTP response (HTML, CSS, JavaScript, images).
5)The browser renders the files and displays the web page.
