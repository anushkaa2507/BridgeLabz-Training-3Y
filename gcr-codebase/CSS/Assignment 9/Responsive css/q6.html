Responsive CSS Cheat Sheet

Filters

Apply visual effects to images.

filter: grayscale(100%);

Media Queries

Apply CSS according to screen size.

@media (max-width: 700px)

Responsive Design

Design that works on different devices.

width: 100%;

Typography

Use flexible font sizes for readability.

font-size: clamp(1rem, 2vw, 2rem);
